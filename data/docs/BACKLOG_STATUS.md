**결정 사항**: 업종은 통계청 KSIC 중분류 2자리로 묶는다. 임의 그룹핑은 서비스 근거로 쓸 수 없어 배제. KRX 업종분류는 내부 API가 차단되어 있고(`LOGOUT`), 공공데이터포털 KRX상장종목정보에는 업종 필드가 없다. WICS/FICS는 상업 데이터. → **DART `induty_code`(= KSIC)가 유일하게 확보 가능한 공식 분류**.

**주의**: `induty_code`는 3~5자리로 길이가 혼재한다(삼성전자 `264`, SK하이닉스 `2612`, 한미반도체 `29271`). 앞 2자리로 자를 때 길이 검사가 필요하다.

### F-26 DART API 클라이언트 구현  — **완료** (2026-08-28)

산출물: **`pipeline/dart_client.py`** + `pipeline/paths.py`

| 성공·실패 응답을 구분한다 | ✔ | `000` 정상 / `013`·`014` 빈 결과 / 그 외 `DartApiError` |
| 호출 실패에 대한 제한적 재시도와 로그가 있다 | ✔ | 네트워크·5xx·`020`·`800`·`900` 지수 백오프 3회 + `logging` + `Stats` 계측 |

**클라이언트가 처리하는 것 (실측 기반)**

- **zip 응답 구분**: `corpCode.xml`·`document.xml`은 zip을 반환. 실패 시에는 zip 대신 XML 에러 문서가 오므로 **매직바이트 `PK`로 판별**
- **`fs_div` 차이**: `fnlttSinglAcnt`는 응답 행에 `fs_div`가 있고, `fnlttSinglAcntAll`은 없다(요청 파라미터일 뿐). 같은 함수로 처리하면 전체재무제표 행이 전부 필터링된다 — **실제로 이 버그로 폴백이 작동하지 않았음**
- **`013`은 정상**: 빈 결과로 처리해야 한다. 오류로 처리하면 상장 이전 연도에서 파이프라인이 멈춘다

**수집 계층에 넘긴 규칙 하나**: `document.xml` 계열은 반환형이 `Path` 라 빈 결과를 표현할 수
없어 `013` 도 예외로 올린다. **`DartApiError.status` 가 `013`/`014` 면 실패가 아니라
"문서 없음"으로 기록해야 한다** (WP-5에서 지킬 것).

캐시 파일명은 기존 `.cache/` 4,201파일과 동일한 규칙이라 그대로 재사용된다.

### R&D 수집이 API 수집 티켓에 묻혀 있다

F-06·F-12는 "DART API에서 재무 항목을 수집"으로만 표현되어 있다. 그러나 **6지표 중 R&D는 API에 없다.**

```
삼성전자 2025 사업보고서 원문
  8.3MB XML / <TABLE> 2,216개 / '연구개발' 45회 등장
  → 이 중 연구개발비 표 하나를 찾아 금액·단위·비율을 뽑아야 한다
```

이번 세션에서 파서를 5번 고쳐서야 통과했고, **나머지 5지표를 합친 것보다 공수가 컸다.** 지금 구조로는 일정 산정이 왜곡되므로 **별도 티켓 분리를 권장**한다.
