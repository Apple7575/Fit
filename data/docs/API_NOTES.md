# OpenDART API 실측 기록

> 기준일: 2026-08-28 / 근거: `scripts/probe_api.py`, `.cache/` 4,201파일
> 문서에 적힌 규격이 아니라 **실제로 받아본 응답**만 적는다.
> 관련: F-26(API 연동), F-24 AC2(호출 제한·오류 응답 확인)

## 1. 호출 제한

| 항목 | 실측 |

| 일 한도 | 20,000건 (계정 기준) |

## 2. 오류 응답 실측

`python scripts/probe_api.py --live` 결과 (2026-08-28, 실제 호출 4건).

| 시나리오 | 엔드포인트 | 응답 |
|---|---|---|
| 잘못된 키 40자 (`000...0`) | `fnlttSinglAcnt.json` | `[010] 등록되지 않은 인증키입니다.` |
| 길이가 틀린 키 (`abc`) | `fnlttSinglAcnt.json` | `[010] 등록되지 않은 인증키입니다.` — 길이 검증 없이 같은 코드 |
| 잘못된 키 | `document.xml` | `[010]` — **zip 이 아니라 XML 에러 문서** |
| 없는 접수번호 | `document.xml` | `[013] 접수번호 오류 : 99999999999999` — **014 가 아니다** |
| 상장 이전 연도 (시프트업 2022) | `empSttus.json` | `[013] 조회된 데이터가 없습니다.` |

**주의 두 가지**

1. 키 오류는 010 하나로 온다. 011(사용 중지)은 아직 못 봤다.
2. `document.xml` 은 실패해도 HTTP 200 이고 본문이 XML 이다. **매직바이트 `PK` 로만 구분된다.**
   존재하지 않는 문서에도 014 가 아니라 013 이 온다 — 접수번호 오타와 "문서 없음"이 같은 코드다.

## 3. status 코드 처리 방침

| 코드 | 의미 | 클라이언트 처리 |
|---|---|---|
| 000 | 정상 | 그대로 반환 |
| **013** | 조회된 데이터 없음 | **정상 흐름.** 빈 `list` 로 반환 (`stats.empty` 증가) |
| 014 | 파일 없음 | 013 과 동일 취급 |
| 020 / 800 / 900 | 요청제한 / 점검 / 미정의 | 지수 백오프 후 최대 3회 재시도 |
| 그 외 | 인증·파라미터 오류 | `DartApiError` 로 즉시 실패 |

**013 을 오류로 올리면 안 된다.** 상장 이전 연도(시프트업 2021~23)에서 파이프라인이 통째로 멈춘다.

`document.xml` 계열은 반환형이 `Path` 라 빈 결과를 표현할 수 없어 013 도 예외로 올린다.
**수집 계층은 `DartApiError.status` 가 013/014 면 실패가 아니라 "문서 없음"으로 기록해야 한다.**

## 4. 엔드포인트별 응답 구조 (실측)

| 엔드포인트 | 행 수 | `fs_div` | `account_id` | 비고 |
|---|---|---|---|---|
| `fnlttSinglAcnt` | 30 (삼성전자 2024) | **행에 있음** (CFS·OFS 혼재) | 없음 | 계정명은 표준화되어 있음 |
| `fnlttSinglAcntAll` | 213 (삼성전자 2024) | **행에 없음** (요청 파라미터일 뿐) | 있음 | 계정명은 회사 원문 (`Ⅰ.영업수익`) |
| `empSttus` | 사업부문×성별 다중 | – | – | 평균근속 = **`avrg_cnwk_sdytrn`** |
| `document.xml` | zip | – | – | 본문 XML 1개 + 첨부. 삼성전자 2025는 8.3MB |
| `corpCode.xml` | zip | – | – | 118,784건. 1회만 받으면 됨 |

### `fs_div` 함정

같은 이름의 필드지만 **두 API에서 의미가 다르다.**

```
fnlttSinglAcnt      요청에 fs_div 를 주지 않아도 연결·별도가 한 응답에 섞여 온다
                    → 행의 fs_div 로 골라야 한다

fnlttSinglAcntAll   fs_div 는 요청 파라미터일 뿐, 응답 행에는 없다
                    → 행을 fs_div 로 거르면 213행이 전부 사라진다
```

한 함수로 처리하면 전체재무제표 행이 전부 필터링되어 **매출 폴백 경로(B·C)가 죽는다.**
그래서 `DartClient` 는 `single_acnt` / `single_acnt_all` 로 메서드를 분리하고,
무엇을 요청했는지는 캐시 파일명(`..._2024_CFS.json`)에만 남긴다.

### 평균근속 필드명

`avrg_cnttk_sdytrn` 으로 짐작했다가 조용히 `None` 을 받았다. 실제는 **`avrg_cnwk_sdytrn`**.
새 API를 쓸 때는 응답 원본을 먼저 찍어볼 것.
