# S15P21A504-90 — Google News RSS 제공 필드·사용조건 조사

- 조사일: 2026-09-05 (KST)
- 작성: Codex, 사용자 승인 PoC
- 상태: 공식 자료 재조사 완료. 운영 수집 소스로 확정할 근거는 부족함

후속 진행: 사용자가 본 조사 이후 실제 수집을 지시하여 한정된 삼성전자 PoC를 실행했다. 아래 보류 판단은 당시 조사 이력이며, 실행 결과는 [91번 문서](91-collection-result.md)에 있다. 수집 성공을 사용조건 허가로 해석하지 않는다.

## 결론

**구글 RSS로 뉴스 정보를 받을 수는 있지만, 우리 서비스의 대량 저장·캐싱·AI 분석까지 허용된다고 확인하지는 못했다.** 네이버 대신 구글을 쓰면 활용 제한 문제가 해결된다는 결론은 낼 수 없다.

- 기술적으로: 이전 탐색에서 RSS 응답을 받았다. 서버가 RSS를 기술적으로 차단했다고 확인한 것은 아니다.
- 사용조건상: 현재 크롤러 지침은 RSS 경로를 허용하지 않는다. 과거 RSS 전용 안내도 발견했지만 현행 한국 서비스 적용 여부는 확인되지 않았다.
- 팀 판단: 구글 RSS는 검토 후보로 유지한다. 운영 소스 확정과 상장사 전체 확대는 보류한다. 소스를 임의로 변경하지 않는다.

1번 조사에서 문서로 확인할 수 있는 사항은 정리했다. 남은 문제는 같은 검색을 반복하는 것이 아니라, 실제 사용 범위에 적용되는 허가·조건을 확인하거나 다른 소스를 검토하는 결정이다.

robots.txt는 저작권 이용허락서가 아니다. 이 보고서의 중단 판단은 현재 robots 내용과 자동 접근에 관한 약관을 함께 고려한 프로젝트 운영 판단이며, 모든 RSS 이용이 불법이라는 법적 결론은 아니다. 별도 계약·허가 또는 RSS에 적용되는 구체적 지침이 있다면 재검토한다.

### 재조사에서 바로잡은 점

기존의 “RSS 접근 불허”는 **robots 규칙을 적용한 크롤러의 경로 판정**이라는 뜻으로 한정한다. HTTP 차단, 모든 RSS 구독 금지, 모든 저장의 불법 여부를 판정한 것은 아니다.

공식 RSS 안내가 전혀 없는 것도 아니다. 과거 안내는 존재한다. 다만 연결된 약관과 UI 설명이 오래되어 현재 허가로 확정할 수 없다. `intl/ko`, `intl/en`, `intl/en_us`의 `news_feed_terms.html`도 직접 조회했으며 모두 HTTP 200의 Google News 고객센터로 이동했다. 조회 성공이 약관 본문 확보를 뜻하지 않는다.

Feedfetcher가 robots를 따르지 않는다는 설명은 Google이 사용자 요청으로 외부 피드를 가져오는 방식이다. 이를 근거로 우리 수집기도 일반 크롤러 지침에서 제외된다고 가정하거나 Google 에이전트를 사칭하지 않는다.

### 사용조건 확인 시 전달할 구체적 범위

학교 프로젝트라는 이유만으로 모든 이용이 비상업적 허용에 포함된다고 가정하지 않는다. 실제 서비스 범위에 대해 다음을 확인해야 한다.

1. 삼성전자부터 시작해 상장사 약 3,000개의 뉴스 제목·게시일·언론사·링크를 정기 수집해 DB에 저장·갱신해도 되는가? 허용 주기와 보관기간은 무엇인가?
2. 이 데이터를 취업 준비용 기업분석 화면에 표시할 때 필요한 출처·링크 표시는 무엇이며, 현재 RSS 전용 조건은 어디에 있는가?
3. 제목과 제공되는 설명을 외부 AI API에 보내 관련사업·중요도를 추론하고 그 결과를 저장할 수 있는가? 모델 훈련은 이번 범위에서 제외한다.

이 질문들은 확인용 초안이며 외부에 전송하지 않았다. 답변을 얻기 전까지 “허용됨”으로 바꾸지 않는다. 학습 활용은 향후 별도 권리 확인 대상이다.

네이버 API는 사용자의 결정에 따라 제외한다. 네이버의 모든 활용을 일괄 금지한다는 독립적인 법률 판단은 이번 조사에서 하지 않았다.

## 테이블 필드 대응

아래 관찰은 작업 승인 이전 `q=Samsung`, `hl=ko`, `gl=KR`, `ceid=KR:ko` 요청의 도구 출력 2건에서 확인한 범위다. 실제 삼성전자 PoC 데이터셋이나 통계로 계산하지 않는다. 해당 전체 XML은 디스크에 보관하지 않았으며 재구성하지 않았다.

| 대상 컬럼 | 입력/처리 | 제한 |
|---|---|---|
| title | RSS title, 끝의 언론사명만 제거 | 원본은 RSS에 보존 |
| description | 표시용 HTML을 텍스트로 검사 | 관찰 2건은 제목 반복. 파서는 반복이면 null, 그 외도 검토 전 null |
| published_at | pubDate → UTC ISO 8601 | 타임존 누락/변환 실패는 null + 오류 기록 |
| original_url | RSS의 직접 외부 링크만 후보로 보관 | Google 경유 주소와 source의 홈페이지를 원문으로 대체하지 않음. 외부 링크도 접근 검증 전 후보 |
| related_business | 향후 AI 추론 | 이번 단계 null |
| importance_score | 향후 AI 추론 | 이번 단계 null |

`news_category`는 사용자가 분류하지 않기로 결정하여 PoC 출력에서 제외했다. DB와 프론트엔드 필드 삭제는 이번 변경에 포함하지 않는다.
