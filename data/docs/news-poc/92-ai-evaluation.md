# S15P21A504-92 — 관련성 모델 비교와 AI 평가

## 최신 결론 — 새 30건 자동 하네스 실행 완료

사용자 요청으로 추가 수동 채점은 생략하고 새 표본의 자동 형식·규칙·반복 안정성을 검증했다. 기존 `evaluation-plan.json`의 사람 우선 검수 계획은 `92-career-holdout/harness-plan.json`으로 대체했다. 카테고리는 제외하고 취준생 유용성 기준과 프롬프트를 그대로 유지했다. 사람 정답을 생성하거나 정확도를 계산하지 않았다.

**실행은 완료했으나 안정적인 운영 적용 Pass는 아니다.** Gemini V1 관련성 결과는 관련 23·무관 6·보류 1건이다. 이 판정을 고정해 첫 30건 및 관련 20건 추가 2회, 총 70개 사업·중요도 응답을 검사했다.

| 검사 | 결과 | 의미 |
|---|---:|---|
| 첫 실행 형식 유효 | 26/30 | 무관·보류 중 4건의 필수 근거 누락 |
| 관련 기사 유효 점수 출력 | 23/23 | 출력률 100%, 정확도 아님 |
| 전체 원시 응답 형식 유효 | 41/70 | 정규화 이전 |
| 전체 정규화 후 형식 유효 | 64/70 | 근거 누락 4개·허용 사업 값 오류 2개는 계속 실패 |
| 관련성 유지·차단·카테고리 제외 규칙 위반 | 0 | 정규화 후 70개 검사. 근거 의미의 타당성은 미측정 |
| 사업 상태·값 3회 일치 | 14/20, 70% | 오류를 포함한 전체 반복 표본 분모 |
| 3회 모두 유효 점수 확보 | 19/20 | 비교 가능한 표본 |
| 위 19건 중 점수 변동 2점 이내 | 14/19, 73.7% | 5건은 2점 초과, 전체 20건 통과율로 해석하지 않음 |

관련성+사업·중요도 한 번 처리 비용은 30건 추정 50.186 Credit(기사당 1.673)이다. 반복 포함 전체 실험은 111.144 Credit, API 요청 시간 합계 85.54초다. 전체 실행은 관련성 4배치·사업 분석 14배치이며 실제 청구 명세 대조나 대량 처리 성능 측정은 아니다.

결과는 `92-career-holdout/harness-result.md`와 JSON, 재집계 절차는 `experiments/audit_career.py`에 있다. 첫 실행 유효 26건과 실패 4건은 `analysis/predictions-1.json`의 schema_valid로 구분한다. 중복 분리 파일은 정리했고, 실제 관련 기사 인계본은 `backend-handoff/candidates.json`에 유지한다. 기존 표본과 프롬프트·원시 응답은 보존했으며 DB 적재는 하지 않았다. 실패는 자동 채점으로 정답을 만들어 채우지 않는다.

**92번 산출물 정리는 완료:** 기존 관련성 V1, 사업 목록·상태, 취준생 중요도 3축, 정규화와 실패 분리, 비용·반복 결과를 기록했다. 사업·중요도 정확도 및 실제 취준생 효용은 미측정이다. 사업 일치 70%와 점수 변동 때문에 운영 안정성을 통과했다고 표시하지 않는다. 모델·프롬프트 개선을 추가한다면 별도 실험으로 관리한다. 다음 최종 범위 판정은 [93번 결과](93-poc-decision.md)를 따른다.

## 최종 선택과 판단 기준

- 관련성: Gemini 2.5 Flash Lite V1을 후속 분석 후보로 유지. GMS에서 실행하며 카테고리는 제외한다.
- 사업: 삼성전자 사업 목록 안에서 specific/company_wide/multiple/insufficient를 구분한다. 특정 사업이 아닌 경우 사업명은 null이다.
- 중요도: 기업 이해 0~4 + 직무 연결 0~3 + 지원 준비 활용 0~3. 합계 0~10. 근거가 부족한 축과 합계는 null이다.
- 관련성 무관·보류와 형식 실패는 데이터 인계 후보에서 제외한다. 사업명 null 자체는 실패가 아니다.
- 새 표본의 추가 사람 채점은 사용자 요청으로 생략했다. 자동 하네스는 정확도나 실제 유용성의 대체 측정이 아니다.

## 관련성 모델을 선택한 근거

회사명 규칙, TF-IDF 기반 통계 모델, 임베딩, GMS 모델과 혼합 방법을 같은 개발 표본에서 비교했다. 개발 표본 400건은 AI 초안을 본 사용자 검수 자료이며 독립 시험 정답이 아니다. 최종 라벨은 관련 266·무관 93·보류 41건이다. 동일 수정 정답으로 Gemini V1 89.0%, V2 85.5%여서 V2를 채택하지 않았다. 상세 비교 수치는 아래 보존 파일에서 확인한다.

새 독립 후보 200건 중 사람이 검수한 54건은 무작위 40건과 오류 탐색용 표본이 섞여 있다. **전체 54건의 일치율을 대표 정확도로 쓰지 않는다.** 무작위 40건의 Gemini 결과는 33/40(82.5%), 관련 17/17, 무관 오통과 4/21(19.0%), 보류 0/2다. 관련 재현율 95% 이상·무관 오통과율 10% 이하·보류 일치율 60% 이상이라는 잠정 기준은 미달이다. 표본이 작아 일반화에는 한계가 있다.

## 사용자 검수와 기존 실험

기존 삼성전자 사업·취준생 점수 30건에 사용자가 수정 의견 없이 동의했다. `92-career-v1/user-review-acceptance.json`에 기록했다. 독립 정답이나 형식 오류 승인으로 취급하지 않는다. 원시 응답과 초안은 유지한다.

이전에 시도한 기업 영향·지속·확정 기준은 취준생 유용성으로 대체했다. 사용하지 않는 기업 영향 실험 디렉터리와 중복 재처리 출력은 정리했으며 현재 판단 근거로 인용하지 않는다.
