# 모의 면접 안내 그림

이 폴더에 파일을 넣으면 리포트 화면에 자동으로 나옵니다. 코드 수정은 필요 없습니다.
파일이 없으면 그 자리는 조용히 비워지므로, 준비된 것부터 하나씩 넣어도 됩니다.

| 파일 이름               | 쓰이는 곳                          | 권장 규격                  |
| ----------------------- | ---------------------------------- | -------------------------- |
| `focus.png`             | 리포트 맨 위 "가장 먼저 고칠 것"   | 정사각 320×320, 투명 배경  |
| `posture-good.png`      | 태도·시선 카드 · 좋은 예           | 가로 640×480 (4:3)         |
| `posture-slouch.png`    | 태도·시선 카드 · 등이 굽은 예      | 가로 640×480 (4:3)         |
| `posture-headdown.png`  | 태도·시선 카드 · 고개가 떨어진 예  | 가로 640×480 (4:3)         |
| `posture-offframe.png`  | 태도·시선 카드 · 얼굴이 화면 밖    | 가로 640×480 (4:3)         |

## 그림 그릴 때 기준

- **실사 사진보다 단순한 일러스트**가 낫습니다. 사람 얼굴이 또렷하게 보이면 초상권 문제가 생기고,
  사용자가 "저 사람은 누구지?"에 시선을 뺏깁니다. 상반신 실루엣 수준이면 충분합니다.
- 네 장(`posture-*`)은 **같은 인물·같은 구도·같은 배경**으로, 자세만 다르게 해 주세요.
  나란히 놓고 비교하는 그림이라 배경이 다르면 비교가 안 됩니다.
- 화면 안에 글자를 넣지 마세요. 설명은 그림 아래 캡션으로 코드가 붙입니다.
- 배경은 흰색 또는 아주 연한 회색. 리포트 카드가 흰색이라 어두운 배경은 튑니다.
- `focus.png` 는 배경을 투명하게 해 주세요. 카드 왼쪽에 아이콘처럼 놓입니다.

## 파일 형식

PNG 를 권장합니다. 한 장당 200KB 이하로 맞춰 주세요(리포트는 한 번에 다섯 장까지 불러옵니다).
